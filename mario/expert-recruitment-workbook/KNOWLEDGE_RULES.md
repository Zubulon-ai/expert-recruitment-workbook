# 专家招募表知识规则

## 字段映射

| 常见原字段 | 目标字段 |
|---|---|
| Company、公司 | 公司 |
| Position、职位、现任/前任 | 职位 |
| Experience、Background、Work Experience | 专家背景 |
| Comments、评价、反馈、TQ回复、Test反馈 | 话题反馈 |
| Available Time、Times、时间、方便时间 | 可访谈时间 |
| Service Charge、费率、倍率、价格 | 费率 |
| 渠道标题、推荐机构 | 推荐方 |

## 备注优先级

1. 疑似同一专家与报价差异；
2. 数据口径冲突；
3. 岗位与主题的匹配度；
4. 时间、含税状态或反馈范围待确认；
5. 其他影响约访决策的信息。

## 疑似重复判断

不能只因为公司相同就判定重复。至少综合比较公司和职位、任职时间、负责业务、反馈数字和措辞、可访谈时间及渠道费率。只输出“疑似”，不要宣称已经确认是同一人。

## 报价比较

- 同币种、同时薪单位、同含税状态时，可以直接比较。
- 一方含税、一方不含税时，不直接计算价差，标记税口径不同。
- 只有倍率没有时薪金额时，只并列展示倍率。
- 不根据历史费率推算缺失报价。

## 数据冲突

出现不同数字时保留所有版本，优先检查：

- 时间：月份、季度、年份；
- 地域：国内、全球、特定城市；
- 产品：主站、极速版、助手、设备；
- 用户口径：设备数、DAU、MAU、去重或不去重；
- 业务边界：单活动、单城、多城、年度；
- 财务口径：含税、不含税、现金预算、资源置换。

## 表格质量标准

- 标题和研究方向清晰；
- 招募问题完整；
- 一位专家一行；
- 长文本可读且不截断；
- 可筛选、可冻结、可继续追加；
- 备注风险突出但措辞审慎；
- 不含编造字段和未经授权的额外个人信息。
